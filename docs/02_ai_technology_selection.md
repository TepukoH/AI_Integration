# 02. Матрица выбора ИИ-технологий

| Процесс | Технология | Обоснование | Риски |
|---|---|---|---|
| Поддержка | LLM + RAG (TF-IDF/эмбеддинги) | Отвечает по базе знаний вуза, минимизирует галлюцинации | Устаревание FAQ, приватность |
| Обратная связь | Лексиконный sentiment + тематизация | Работает офлайн, прозрачно, быстро | Ограниченный словарь |
| Приёмная комиссия | Классификация обращений (ML) | Автомаршрутизация в Directum RX | Дисбаланс классов |
| LMS | Предиктивная аналитика | Раннее выявление отстающих | Требует исторических данных |
| Мобильная платформа | ASR + суммаризация | Конспекты лекций, запись разговоров | Качество ASR на русском |

**Интеграция с уже существующими решениями:** Synergy Start, VOCAL AI, мобильная платформа с МТС — используются как источники данных и каналы доставки ответов ассистента.
