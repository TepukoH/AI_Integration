# 01. Анализ бизнес-процессов «Синергии»

| Процесс | Узкое место | Кандидат на ИИ |
|---|---|---|
| Приёмная комиссия | Рост обращений в пик сезона, ручные ответы | LLM-ассистент + RAG |
| Поддержка студентов | Долгое время первого ответа | LLM-ассистент |
| Деканат | Типовые справки, ручной ввод | Классификация обращений + автозаполнение |
| Обратная связь | Ручная обработка отзывов | Sentiment + тематизация |
| Учебный процесс | Позднее выявление отстающих | Предиктивная аналитика (LMS) |
| Документооборот (Directum RX) | Ручная маршрутизация | Классификатор + рекомендации маршрута |

## Приоритет для пилота
1. ИИ-ассистент приёмной комиссии/поддержки — быстрый эффект, малый риск.
2. Анализ обратной связи — офлайн, не влияет на студенческий опыт.
3. Предиктивная аналитика LMS — второй этап после сбора данных.
